# PARK HYOJIN — Visual Archive

Single-page, static portfolio website using original images extracted from the supplied PDF portfolio.

## Run
Open `index.html` in a browser. For the best behavior, serve the folder locally: `python -m http.server 8000` and open `http://localhost:8000`.

## Deploy
Upload the folder contents to a GitHub Pages repository, or deploy the folder through Netlify / Vercel as a static site. No build process, package manager, or API keys required.

## Interactions
- Horizontal gallery automatically scrolls gently from right to left.
- Hover stops autoplay; drag or mouse wheel to control gallery position.
- Click/Enter opens an individual project archive.
- `BACK TO WORKS` returns to the belt without resetting its previous scroll position.
- Mobile uses touch swiping. Reduced motion settings disable autoplay.

## Before submission
- Proofread all project credits and role descriptions; adapt the selection to the CAMWUS job requirements.
- Check the gallery and image crops at desktop and mobile widths; replace any photographs that do not meet your quality expectations.
- Verify contact email and Instagram URL; add a PDF button if you want to provide the PDF as a separate downloadable file.
- Only use artwork, photography and video for which you have relevant publication permissions.
